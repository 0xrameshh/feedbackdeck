# Rules you should remember during development
- you should make sure to keep folder structure and codebase clean 
- make sure no of lines in a files is not greater than 200
- if you run into error, ask user for docs or solution. dont give vague solutions
- search docs online if you are unsure about method
- during backend development make sure to follow drizzle-docs. dont use raw sql queries
- if you are not sure about something, ask user for help
